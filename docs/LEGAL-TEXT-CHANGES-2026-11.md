# Legal-text changes, November 2026 (source-checked by AI review, not attorney-reviewed)

This file continues [docs/LEGAL-TEXT-CHANGES-2026-10.md](LEGAL-TEXT-CHANGES-2026-10.md) for
changes after release 2026.11.07.1. It records proposed corrections to general reference
material, their public-source checks and an independent second AI review. Each row names the pull
request that proposes it and remains subject to the maintainer's adoption by merge; the maintainer,
who is not a lawyer, records the merge and its date in the row's Status column when it happens. No
attorney review is represented. [LEGAL_NOTICE.md](../LEGAL_NOTICE.md) applies.

Each changed passage carries a pinpoint in its text or in an adjacent HTML comment marked
`SOURCE-CHECKED BY AI REVIEW, NOT ATTORNEY-REVIEWED (checked <date>)`. No citator content of any
kind is used: status statements are a reading of the public docket or order with a pinpoint.
Line numbers are those of the file after the change. "Old text" and "New text" omit the adjacent
source comments. Finding numbers are those of the maintainer's assessment record, which is kept
outside this repository.
